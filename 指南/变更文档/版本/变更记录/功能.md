- 🟡 **代码已移植，端到端待补**：后端/前端框架已落地，但缺独立产物或后端对接，暂不能完整使用；括号内注明还差什么。

## 一、v0.8.2 升级新增功能

### 1.1 知识库与检索

| 功能 | 状态 | 功能说明 | 用法 / 入口 |
|------|------|---------|------------|
| **智能体检索工具统一升级** | ✅ | 旧的 4 个检索工具（knowledge_search / grep_chunks / list_knowledge_chunks / get_document_info）合并为 3 个更聚合的工具：`search_knowledge`（向量+关键词+MMR+Rerank 统一检索）、`read_document`（读文档，可聚焦 chunk 并扩展上下文）、`list_documents`（列文档）。Agent 在对话中自动调用，旧工具名已退役映射。 | 在智能体对话中直接提问即可，无需手动选工具；旧会话历史里的工具名仍可正常展示。 |
| **大文件上传动态超时** | ✅ | 上传超时不再固定 5 分钟，改为按文件大小自动计算（下限 5 分钟，之后每 10MB 约 1 分钟）。知识文件、技能包、模型等所有上传接口统一生效。 | 直接上传大文件即可，无需任何配置；小文件行为不变。 |
| **Wiki 跨知识库搜索** | ✅ | 一次在最多 32 个知识库中联合搜索 Wiki 页面，按标题 > slug > 摘要 > 正文的优先级排序，返回全局 top-N。 | 调用 `POST /api/v1/wiki-search`，请求体传 `knowledge_base_ids` 与 `query`；支持跨租户分享的知识库。 |
| **Wiki 引用片段包含图片描述** | ✅ | Wiki 写入时，传给编辑模型的引用片段会自动注入图片的 OCR 文字与描述（`<image>` 标签），让图片中的信息能被 Wiki 页面吸收。 | 自动生效（需已配置 VLM）；文档含图且 Wiki 开启时无需手动操作。 |

### 1.2 智能体与外部集成

| 功能 | 状态 | 功能说明 | 用法 / 入口 |
|------|------|---------|------------|
| **内置 MCP Server** | ✅ | 把 WeKnora 自身作为 MCP 服务暴露给外部 Agent：Streamable HTTP 传输、Bearer Token 认证、工具白名单、知识库作用域，内置 12 个工具（检索/对话/Wiki/写入）。 | 「集成设置 → MCP Server」页创建端点、生成 token、复制客户端配置片段；外部 MCP 客户端用该 token 连接 `/mcp/endpoints/:id`。 |
| **本地浏览器（BrowserSkill）** | 🟡 | AI 智能体可直接操作用户自己的浏览器：导航、点击、输入、截图、滚动、前进/后退/刷新，复用用户浏览器的登录态与 cookie。后端全链路（设备配对、ed25519 公钥认证、WebSocket 连接守护、任务请求-响应、人工介入状态持久化）+ `browser` Agent 工具（仅当用户有已配对设备时才注入）+ 设置页（配对令牌、设备列表/移除）+ 聊天结果卡（截图、页面内容、运行状态）均已移植；**独立的浏览器扩展未开发**，端到端暂不可用。 | 「设置 → 数据与扩展 → 浏览器连接」生成一次性配对令牌（5 分钟有效）；需部署开启 `LOCAL_BROWSER_ENABLED`。扩展侧就绪前无法实际驱动浏览器。 |

### 1.3 Wiki 本体质量（自动生效，无需操作）

| 功能 | 状态 | 功能说明 | 用法 / 入口 |
|------|------|---------|------------|
| **Wiki 去重别名匹配增强** | ✅ | 去重改为四向交叉比对（名称/别名 × 名称/别名）、合并标准从「任一满足」收紧为「全部满足」，并加入反歧义约束（共享缩写不足以证明同一事物），减少误合并与孪生页面。 | 自动生效。 |
| **Wiki 页面续写机制** | ✅ | Wiki 页面改写被 max_tokens 截断时，自动从中断处续写（最多 3 轮），写完以 `(complete)` 哨兵收尾；仍写不完则拒绝写回残缺页，避免越合越坏。 | 自动生效。 |
| **Wiki 同名页面跨类型复用** | ✅ | LLM 对同一事物的类型判断在 entity/concept 间漂移时，同类型找不到同名页面会自动跨类型复用已有页面，杜绝「孔子」同时出现实体页与概念页两份。 | 自动生效。 |
| **Wiki 摄入 panic 恢复** | ✅ | Map 阶段、Reduce 阶段各加 panic 兜底，单个坏文档/坏页面的空指针不会再搞垮整个 worker 进程。 | 自动生效。 |
| **Wiki follow-up 动态扇出** | ✅ | 文档大积压时按待处理数与可用槽位动态并发调度 follow-up 任务（Redis 信号量控上限 + 对账 + 兜底探针），吞吐更高；无 Redis 时自动退化为单任务。 | 自动生效（依赖 Redis）。 |

## 二、v0.8.3 升级新增功能

### 2.1 知识库与图片

| 功能 | 状态 | 功能说明 | 用法 / 入口 |
|------|------|---------|------------|
| **图片画廊（Image Gallery）** | ✅ | 知识库新增「画廊」Tab：把文档中抽取的图片统一摊平成可浏览的卡片墙。支持关键字搜索（搜图片描述或图中文字）、按来源文档筛选、按创建时间排序、启停切换、点击查看大图。底层是 `chunk_images` 投影表，由触发器随 `chunks.image_info` 自动维护。 | 知识库页面顶部切到「画廊」Tab；瀑布流分页加载；点卡片打开大图查看器（右侧显示图片描述 / 图中文字 / 基本信息 / 来源文档）。 |
| **图片属性观察管线（smartocr）** | ✅ | 加工图片时可选两条管线：`default`（普通 caption+OCR，行为同前）与 `smartocr`（一次 VLM 请求同时归纳属性 + caption，再按需跑 OCR，可省 OCR 调用）。产出图片属性（如是否含文字、是否为数据图表）供画廊筛选。 | 知识库「编辑 → 多模态」区选管线、配好 VLM 模型后**重新解析**文档才生效；`ImageAttrsEnabled` 默认关，开了 smartocr 才有属性数据。 |
| **抽取图片资源授权绑定** | ✅ | 文档解析后自动把抽取落盘的图片资源绑定到所属知识库；KB 文件代理只服务有绑定的图片，否则跨工作区查看一律 403（图能列出却加载失败的根因修复）。 | 自动生效；新加工文档走新代码自动绑定。换 VLM 后建议重新加工一次验证图片可显示。 |
| **原文引用导航** | ✅ | 聊天回答里的引用不再只打开片段文本，而是直接打开原始文件并**定位高亮**：PDF 跳到页码/区域、Word 定位段落、Excel 定位行、PPTX 定位幻灯片、图片定位 bbox、音频定位时间点。 | 聊天引用点击即进入抽屉「原文」模式；PDF 用 pdf.js 渲染文本层并高亮。存量文档需重新解析才有定位器。 |

### 2.2 Wiki 与图谱

| 功能 | 状态 | 功能说明 | 用法 / 入口 |
|------|------|---------|------------|
| **Wiki 写保护（表行丢失拒绝）** | ✅ | LLM 整页重写时若丢失已存储页面的表格行，拒绝写入并保留原页面（摄入阶段容忍 20% 丢失，Agent 整页写入零容忍）。 | 自动生效。 |
| **Wiki 反链标题解析** | ✅ | 页面详情接口返回所有反链的中文标题映射，反链列表即使页面未在侧边栏加载也能显示可读标题，而不是 slug。 | 自动生效；反链区直接显示中文标题。 |
| **Wiki 图谱分组布局** | ✅ | 知识图谱自动做社区发现：联系紧密的页面成簇、分块摆放并给地标名称；支持点簇飞入、只看这一组、下拉切换分组、Esc 返回全图、图例开关无关联页面。 | 知识库「Wiki 图谱」Tab；点击簇/地标镜头聚焦，底部聚焦条切换分组。 |
| **检索质量优化** | ✅ | 混合检索 RRF 分数归一化到 [0,1]、BM25 分数缩放；MMR 改倒排索引实现更快；`summarize` 意图不再触发知识库检索，直接用上下文做纯摘要。 | 自动生效（对话/检索结果质量提升）。 |

## 三、VLM 选型建议（图片管线实测结论）

> 适用于「图片画廊 / smartocr 管线 / Wiki 图片描述」等依赖视觉模型的场景。

| 模型 | 是否推荐 | 说明 |
|------|---------|------|
| **DeepSeek-V4.1-Flash** | ✅ 推荐 | 通用 VLM：caption 主动按原图分层组织、OCR 用网格还原表格布局、二维码诚实输出"未识别到文字"。 |
| Qwen / Qwen3.8-27B | ✅ 可替代 | 输出干净不复读，中文 OCR 强；空间还原与结构化略逊于 DeepSeek-V4.1-Flash。 |
| ~~DeepSeek-OCR~~ | ❌ 勿用 | OCR 专用模型，对复杂架构图会把标签列表循环重复 3-4 轮（ocr_text 达 9KB+）。 |

换模型在知识库「编辑 → 多模态」区选择即可，无需改代码；换完建议重新解析一篇含图文档验证。
